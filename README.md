# حسّنها قبل الإرسال - النموذج الأولي

موقع عربي RTL لتحسين نبرة الرسائل والمنشورات مع الحفاظ على الرأي والمعنى.

## ما يعمل الآن
- كتابة رسالة وتحليلها.
- أمثلة جاهزة للتجربة.
- إظهار نقاط التحسين المحتملة.
- عرض صياغة متوازنة + رسمية + ودية + مختصرة.
- نسخ النتيجة.
- رفع صورة أو بوست وإرسالها لمسار الذكاء الاصطناعي.
- وضع تجريبي تلقائي للنصوص إذا لم يتم ربط نموذج ذكاء اصطناعي.

## التشغيل
```bash
npm install
npm run dev
```
ثم افتح: http://localhost:3000

## تفعيل الذكاء الاصطناعي
انسخ `.env.example` إلى `.env.local` ثم عيّن `AI_MODEL` إلى نموذج متعدد الوسائط يدعم النص والصور عبر Vercel AI Gateway.
على Vercel يمكن استخدام مصادقة AI Gateway/OIDC أو API key حسب إعداد المشروع. اسم النموذج غير مثبت في الكود حتى يمكن تغييره بسهولة عند النشر.

## المبدأ التحريري
لا يغيّر الموقع رأي المستخدم. دوره هو تقليل السخرية والتجريح والتعميم والاتهام القطعي، وفصل نقد الفكرة عن الشخص، مع الحفاظ على المقصود الأصلي.

## الهوية
