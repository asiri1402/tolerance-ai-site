# حسّنها قبل الإرسال

موقع عربي RTL يراجع الرسالة أو المنشور قبل إرساله، ويُزيل العبارات التي قد تُفهم كهجوم أو سخرية أو تعميم، **مع الحفاظ على رأي المستخدم**، ويشرح سبب كل تعديل.

## كيف يعمل
1. **النموذج يقترح تعديلات فقط**: كل تعديل مقطع منسوخ حرفيًا من الرسالة + بديله + فئته + سببه. لا يعيد كتابة الرسالة.
2. **الخادم يطبّق التعديلات على النص الأصلي**: ما عدا المقاطع المعدَّلة يبقى كما هو بالحرف (فواصل الأسطر والرموز والترقيم). اقتباس غير موجود في النص يُرفض.
3. **فحوص حتمية**: لا أرقام ولا روابط ولا إشارات ولا رموز تعبيرية جديدة في البدائل، ولا إعادة كتابة لمعظم النص، ولا نمو مبالغ فيه في الطول.
4. **مدقق دلالي اختياري** (نموذج صغير): هل بقي الموقف؟ هل أُضيف اعتذار أو مديح أو معلومة؟
5. **إعادة محاولة واحدة** بملاحظة محددة، ثم إن فشلت تُعرض ملاحظات دون نص بديل (`degraded`) والنص الأصلي كما هو.
6. **التهديد وإيذاء النفس والكراهية** لا تُجمَّل (`no_rewrite`).
7. **الصور على خطوتين**: يُقرأ النص ويراجعه المستخدم، ثم يُحسَّن كأي نص. تُصغَّر الصورة في المتصفح وتُزال بيانات EXIF قبل الإرسال.

حالات الرد: `ok` · `unchanged` (النص سليم ويعود حرفيًا) · `no_rewrite` · `degraded` · `error`.
عند تعذر النموذج لا يقول الموقع إن النص سليم؛ يعرض فحصًا أوليًا للكلمات الحادة فقط ويوضح ذلك.

## التشغيل
```bash
npm install
cp .env.example .env.local   # ثم اضبط AI_MODEL
npm run dev                  # http://localhost:3000
```
بدون نموذج: للتطوير ضع `MOCK_AI=1` في `.env.local` (محرّر وهمي يحذف الألفاظ الحادة المعروفة فقط، ولا يعمل في الإنتاج).

## الإعدادات (`.env.example`)
| المتغير | الوظيفة |
|---|---|
| `AI_MODEL` | يفعّل الذكاء الاصطناعي، ويُستعمل لقراءة الصور. مثل `anthropic/claude-haiku-5.5`. |
| `AI_EDITOR_MODEL` | نموذج التحرير وإعادة الصياغة. الافتراضي `anthropic/claude-sonnet-5.5` (أعلى جودة بنحو 20 ضعف تكلفة Haiku). |
| `AI_VERIFIER_MODEL` | نموذج المدقق الدلالي (اختياري، يُفضَّل نموذج صغير). |
| `AI_FALLBACK_MODELS` | نماذج بديلة مفصولة بفواصل تُجرَّب عند فشل الأساسي. |
| `AI_ZDR=1` | طلب عدم الاحتفاظ بالبيانات لدى المزوّد (قد يتطلب خطة تدعمه). |
| `DAILY_REQUEST_CAP` | سقف يومي لطلبات الخادم (افتراضي 3000، لكل نسخة تشغيل). |

على Vercel تُستعمل مصادقة OIDC لـ AI Gateway فلا حاجة لمفتاح في الإنتاج. لا يوجد أي متغير بادئته `NEXT_PUBLIC`، ولا يصل أي سر إلى المتصفح.

## الخصوصية
- لا قاعدة بيانات ولا تخزين للنصوص أو الصور.
- السجلات تحوي بيانات وصفية فقط (الطول، الحالة، الزمن). لا نص ولا صور.
- تحديد المعدل في الذاكرة هو حماية أولية فقط؛ للإنتاج فعّل Vercel Firewall rate limiting على `/api/improve`.

## الاختبار
```bash
npm test                         # اختبارات الوحدات (لا تحتاج نموذجًا)
npm run eval -- --baseline       # المنطق القديم على مجموعة التقييم
npm run eval -- --mock           # الخط الأنبوبي مع محرّر وهمي (يختبر الفحوص فقط)
npm run eval                     # الخط الأنبوبي مع النموذج (يحتاج AI_MODEL)
```
التفاصيل في [evals/README.md](evals/README.md).

## المبدأ التحريري
لا يغيّر الموقع رأي المستخدم. النقد الحازم للفكرة أو العمل أو السلوك يبقى. الذي يُعدَّل هو الهجوم على الشخص والتعميم الاتهامي والسخرية والوصف الجارح والإقصاء.
