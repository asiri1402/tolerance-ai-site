# مجموعة التقييم

`cases.jsonl`: 56 حالة **أولية كتبها المساعد** وتحتاج مراجعة معلم لغة عربية ومرشد قبل اعتماد أي رقم منها.

الحقول: `expect` = `clean` (يجب أن يعود حرفيًا) | `change` (يجب أن يُكشف ويُعدَّل) | `no_rewrite` (تهديد/إيذاء نفس/كراهية).
`must_remove`: عبارات يجب ألا تبقى. `must_keep`: عبارات تعبّر عن الموقف ويجب أن تبقى.

## ما يقيسه `npm run eval` (حتمي)
- نسبة النص السليم الذي عاد **حرفيًا** دون أي تغيير.
- نسبة الحالات الحادة التي كُشفت، ونسبة التي فاتت وأُعلنت سليمة (أخطر فشل).
- بقاء عبارات الموقف وإزالة العبارات الجارحة.
- حالات `no_rewrite`، ونسبة الفشل/التدهور، وزمن الاستجابة p50/p95.

## ما لا يقيسه (يحتاج مقيّمين بشريين)
- هل بقي موقف المستخدم فعلًا؟ (1–5، مع صفر حالات انعكس فيها الموقف.)
- هل البديل طبيعي ويحفظ اللهجة؟ هل السبب واضح؟
- دقة قراءة الصور: صور حقيقية (لقطات واتساب وتويتر، خط يد، دقة منخفضة) مع نص مرجعي ونسبة خطأ الحروف.

## التشغيل
`--runs 3` لقياس التذبذب، و`--filter change_sharp` لمجموعة واحدة، و`--verify` لتفعيل المدقق.
النتائج تُحفظ في `evals/results/` (خارج git).

لا تضع رسائل طلبة حقيقية في المجموعة. استعمل نصوصًا مكتوبة أو مصطنعة.
